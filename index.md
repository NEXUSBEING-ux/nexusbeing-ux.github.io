- **Upload PDF Notes**: Simple interface to upload your notes.

## 🛠️ Tech Stack

- **Python 3.9+**: The programming language for development
- **pypdf**: Used for extracting text from PDF files
- **Transformers**: The library from Hugging Face for text summarization
- **Torch**: Framework used for deep learning tasks
- **Streamlit (Optional)**: User interface for a smoother experience

## 🧠 How It Works

1. Upload your PDF file in the application.
2. The application uses pypdf to extract the text.
3. facebook/bart-large-cnn processes the text.
4. You receive a concise, exam-focused summary.
